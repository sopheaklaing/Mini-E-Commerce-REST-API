LINUX COMMAND CHEAT SHEET
=========================

NOTE:
These commands are mainly for Linux/Ubuntu/WSL.
Some commands also work in macOS or PowerShell, but behavior can differ.

1. TERMINAL / NAVIGATION
------------------------
pwd                 Show current directory
ls                  List files and directories
ls -l               Detailed list
ls -la              List all files including hidden files
ls -lh              Detailed list with readable sizes
cd folder           Enter a directory
cd ..               Go to parent directory
cd ~                Go to home directory
cd /                Go to root directory
cd -                Go to previous directory
clear               Clear terminal
history             Show command history
exit                Exit terminal

2. FILES AND DIRECTORIES
------------------------
mkdir folder                Create directory
mkdir -p a/b/c              Create nested directories
touch file.txt              Create empty file
cp file.txt backup.txt      Copy file
cp -r folder backup         Copy directory
mv old.txt new.txt          Rename/move file
mv file.txt folder/         Move file
rm file.txt                 Delete file
rm -r folder                Delete directory recursively
rm -rf folder               Force delete directory (BE CAREFUL)
rmdir folder                Remove empty directory

3. VIEW / READ FILES
--------------------
cat file.txt                Display entire file
less file.txt               Read file page by page
more file.txt               Read file page by page
head file.txt               Show first lines
head -n 20 file.txt         Show first 20 lines
tail file.txt               Show last lines
tail -n 50 file.txt         Show last 50 lines
tail -f file.log            Follow a log file live

4. CREATE / WRITE FILES
-----------------------
nano file.txt               Open/edit file with nano
vim file.txt                Open/edit file with Vim
vi file.txt                 Open/edit file with vi

echo "Hello" > file.txt     Write/overwrite file
echo "Hello" >> file.txt    Append to file
cat > file.txt              Write multiple lines, Ctrl+D to finish
cat >> file.txt             Append multiple lines, Ctrl+D to finish

5. NANO SHORTCUTS
-----------------
Ctrl + O                    Save
Enter                       Confirm filename
Ctrl + X                    Exit
Ctrl + K                    Cut line
Ctrl + U                    Paste
Ctrl + W                    Search
Ctrl + G                    Help

6. VIM BASIC COMMANDS
---------------------
i                           Insert/write mode
Esc                         Exit insert mode
:w                          Save
:q                          Quit
:wq                         Save and quit
:q!                         Quit without saving
dd                          Delete line
yy                          Copy line
p                           Paste
u                           Undo

7. SEARCH
----------
find . -name "file.txt"     Find exact filename
find . -name "*.log"        Find log files
find /var/www -name "*.php" Find PHP files
grep "error" file.log       Search text
grep -i "error" file.log    Case-insensitive search
grep -r "APP_KEY" .         Search recursively
grep -n "error" file.log    Show line numbers
grep -v "error" file.log    Show lines NOT matching
which php                   Find executable location
whereis nginx               Find program locations

8. WORD / LINE / BYTE COUNT
---------------------------
wc file.txt                 Lines + words + bytes
wc -l file.txt              Count lines
wc -w file.txt              Count words
wc -c file.txt              Count bytes

IMPORTANT:
The command is "wc", NOT "wcl".

9. TEXT PROCESSING
------------------
echo "Hello"                Print text
printf "Hello\n"            Print formatted text
sort file.txt               Sort lines
uniq file.txt               Remove adjacent duplicate lines
sort file.txt | uniq        Sort and remove duplicates
cut -d',' -f1 file.csv      Extract column
awk '{print $1}' file.txt   Print first column
sed 's/old/new/g' file.txt  Replace text in output

10. PIPES AND REDIRECTION
-------------------------
command1 | command2         Send output to another command
command > file.txt          Overwrite file with output
command >> file.txt         Append output to file
command < file.txt          Use file as input
command 2> error.log        Redirect errors
command > out.log 2>&1      Redirect output and errors

Examples:
ps aux | grep nginx
cat file.log | grep error
ls -la > files.txt
echo "hello" >> file.txt

11. PERMISSIONS
---------------
ls -l                       Show permissions
chmod 755 file              Set permissions
chmod 644 file              Set permissions
chmod +x script.sh          Make script executable
chmod -R 755 folder         Change recursively
chown user:user file        Change owner/group
chown -R user:user folder   Change recursively

Permission numbers:
7 = rwx
6 = rw-
5 = r-x
4 = r--
3 = -wx
2 = -w-
1 = --x
0 = ---

Common:
chmod 755 script.sh
chmod 644 file.txt
chmod +x script.sh

38. IMPORTANT SAFETY
--------------------
Be careful with:
rm -rf
sudo rm -rf
chmod -R
chown -R
docker system prune
kill -9
sudo systemctl stop

Always check the path before deleting or changing permissions.

39. POWERSHELL VS LINUX
-----------------------
If your prompt looks like:
PS D:\Project>

You are using Windows PowerShell.

PowerShell:
clear
cls
notepad .env

Linux/Ubuntu:
clear
nano .env
vim .env

For Linux practice on Windows, use WSL + Ubuntu.
